# AI-Engineering

_Learn AI engineering for free._

## The aim of this repository

This repository will teach AI engineering, **for free**. The goal is to make the skills behind building real AI systems available to everyone — no paywalls, and no assumed machine-learning background.

We'll go from fundamentals to shipping working systems: how models actually behave, prompt and context design, retrieval, evaluation, observability, cost and latency, deployment, and the feedback loops that keep a system improving. Clear explanations and working examples, not theory alone.

## What we'll cover

- How LLMs actually behave, and where that differs from intuition
- Prompt and context design
- Retrieval-augmented generation
- Evaluation and testing of non-deterministic systems
- Observability, tracing, and cost tracking
- Deployment, scaling, and rollback
- Feedback loops that keep a system improving
